# Контракты CppDefense

[English](README.md) | **Русский**

Этот каталог — версионируемая граница между Backend, Runner, C++ worker и
производителями импортируемых архивов.

- `manifests/` — схемы manifest внутри ZIP и корректные примеры;
- `worker/v1/` — JSON-протокол stdin/stdout для `cpp-defense-worker`;
- `openapi/` — browser/API и закрытый Runner HTTP contract;
- `tests/` — примеры, которые обязаны отклоняться;
- `requirements-ci.txt` — зафиксированные версии валидаторов CI.

Сначала меняется контракт, затем реализация. Ломающее изменение worker,
manifest или HTTP требует новой major-версии; существующий v1 нельзя незаметно
переопределять.

## Проверка

Установите зависимости из `requirements-ci.txt` в отдельное Python-окружение и
выполните команды из `.github/workflows/contracts.yml`. CI проверяет сами JSON
Schema по Draft 2020-12, положительные и отрицательные примеры, OpenAPI 3.1 и
реальные ответы собранного worker.

В примерах допустимы только синтетические личности и hashes. Настоящие работы,
архивы, логи и результаты студентов запрещены в этом каталоге и публичной
истории Git.
