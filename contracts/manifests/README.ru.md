# Контракты ZIP manifest

[English](README.md) | **Русский**

Стандартное имя файла внутри любого архива: `cppdefense-manifest.json`.

- `group-v1.schema.json` описывает архив группы с несколькими работами;
- `lab-v1.schema.json` описывает один проект одного студента и одной лабы.

JSON Schema — только первый уровень. Backend дополнительно проверяет:

- UTF-8 и размер manifest не более 1 МиБ;
- Unicode NFC и уникальность путей без учёта регистра;
- уникальность student/lab и project paths, отсутствие пересечений каталогов;
- отсутствие ZIP Slip, ссылок, devices, encrypted entries и вложенных ZIP;
- лимиты числа файлов, размеров, сжатия и коэффициента распаковки;
- права на группу, лабораторную и импорт;
- корневой `CMakeLists.txt` и минимум один C/C++ source;
- неизменяемое хранилище и атомарный review/apply.

`$id` использует текущий публичный origin. Его будущая смена должна быть явным
изменением контракта. В `examples/` лежат корректные примеры, а
`../tests/invalid-lab-zip-slip.json` обязан оставаться отклоняемым.
