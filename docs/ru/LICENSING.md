# Смена лицензии

[English](../LICENSING.md) | **Русский**

Правообладатель: Zakharev Georgii.

Revision, добавившая этот документ, заменила корневое MIT-уведомление на
CppDefense Proprietary Source-Available License. Репозиторий остаётся публичным
для просмотра портфолио и оценки при найме.

Изменение было подготовлено относительно commit
`f735acc4a1caf5df5a87162ce302953e0e33bd0e`, где корневой `LICENSE` был MIT.
Новые условия действуют для материалов, предложенных под ними начиная с commit,
в котором появился этот документ; сама запись не объявляет новый release.

Ранее выданные MIT-права не отзываются. Уже распространённые копии и исходные
материалы под MIT сохраняют эти разрешения: ограничения нельзя применить
задним числом простой заменой notice. Сторонние и студенческие материалы
остаются у своих правообладателей и под своими лицензиями.

Текущие основные условия находятся в [`LICENSE`](../../LICENSE).
